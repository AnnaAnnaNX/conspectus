# 📖 Conspectus

Веб-сервис для структурирования и работы с текстом.

[🌐 Живая демонстрация](https://annaannanx.github.io/conspectus/) · [🎬 Видео-демо](https://rutube.ru/video/eda9622580800fa00b0233f0fb0cdbe8/)

## О проекте

**Conspectus** — это сайт для работы с текстом. Вы можете выделять слова и фразы, отмечая их как **главные** или **интересные**. После разметки текста доступны режимы отображения:

- **Показать всё** — исходный текст;
- **Только главное** — остаются лишь главные фрагменты;
- **Главное и интересное** — отображаются обе категории.

Это помогает при подготовке к экзаменам или для более эффективной работы с большими объёмами текста. Готовую разметку можно **сохранить в отдельном HTML-документе**.

## ✨ Возможности

- ✍️ **Выделение главного** в тексте;
- 💫 **Режимы отображения** — «всё», «главное», «главное и интересное»;
- 🚦 **Быстрое переключение** между режимами;
- 📥 **Скачивание конспекта** в виде HTML-документа.

## 🛠 Технологии

| Технология | Роль |
|------------|------|
| **Vue 3** | Фреймворк для интерфейса |
| **DOM API** | Работа с блоками HTML при выделении участков текста |
| **Selection API** | Определение того, что именно выделил пользователь |
| **CSS / HTML** | Разметка и стилизация |
| **Vitest** | Тестирование, включая сложные случаи выделения |

## 🔍 Как это работает

Для выделения участков текста внутри общего текста используется **DOM API**: разметка производится на уровне HTML-блоков. Чтобы понять, какой именно фрагмент выбрал пользователь, применяется **Selection API** — стандартный браузерный интерфейс для доступа к выделенной области документа[reference:2].

Тестирование (включая сложные случаи, например когда внутри блока «интересное» выделяется блок «главное») выполняется с помощью **Vitest**.
